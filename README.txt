Dilip Yadav Dairy App - Complete Source Code
============================================

यह ZIP फाइल आपके पूरे डेयरी ऐप का 100% सोर्स कोड है (React + TypeScript + Vite + Tailwind CSS)।

ऐप चलाने का तरीका (How to run locally):
1. इस ZIP फाइल को Extract / Unzip करें।
2. कंप्यूटर में Node.js (v18+) इंस्टॉल होना चाहिए।
3. इस फोल्डर में टर्मिनल (Command Prompt / VS Code Terminal) खोलें और ये कमांड चलाएं:
   npm install
   npm run dev
4. ब्राउज़र में http://localhost:3000 खोलें।
5. प्रोडक्शन बिल्ड (dist/) बनाने के लिए चलाएं:
   npm run build
